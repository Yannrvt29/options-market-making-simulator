# Working together

This is Yann's options market-making learning project.

- Read README.md and MILESTONE_01.md before working.
- Build one small milestone at a time. Do not implement the whole roadmap.
- Ask Yann to implement the core calculations. Review his work and give hints before solutions.
- Explain the financial intuition and design choices briefly, in plain language.
- Start with Python, NumPy and SciPy. Keep the architecture simple.
- Use contract multiplier 1 initially. State time, rate and volatility units.
- Keep historical observations separate from simulated order flow and fills.
- Never invent performance results. State assumptions and limitations.
- Keep dependencies pinned and record random seeds when randomness is introduced.
- Validate pricing with reference cases, finite differences and, once puts exist, put-call parity.
- Profile a working implementation before considering C++.
- Preserve unrelated changes. Never commit credentials, local environments or unlicensed market data.
